# App 易用性、稳定性与适应能力

## P0 第一批：输入与结果可解释性

- 上传 MusicXML 后进行本地结构预检：格式、大小、声部、反复、移调、拍号、音域；保留后端权威校验。
- 无效结构在 POST 前拦截，预检不是 OMR 识别正确性的保证。
- 音频上传检查可读取的时长与 180 秒上限；WebM 缺失时长元数据时使用解码回退，15 秒超时清理资源。
- 报告质量与演奏分数独立：`complete / complete_with_rescue / partial / insufficient_evidence`；真实 0 分保持 0，null 明确显示未计分。
- 报告包含可判比例、补救原因、覆盖小节、下一步操作、诊断 ID 和版本。自动补救后不宣称边界已经人工验证。
- 静态导出首帧语言与服务端保持一致，挂载后恢复语言偏好，避免英文偏好刷新触发 hydration 错误。
- API 添加可选 `quality` 与 `diagnostics`，旧报告仍兼容；新增字段经响应守卫校验。
- 任务包含失败阶段、错误类型、耗时、输入摘要 hash；日志不记录音频、谱面、文件名、密钥或异常消息。
- health 公布弦乐算法版本和质量契约版本，不能单凭 health 判断行为正确。
- 保留独立音高/跟拍评分；`overallScore` 从未属于现有契约，如需综合分应另行明确权重及校准。

验收：真实 0 分、缺失评分、八度/BPM 补救、坏 XML 禁止提交、命名空间及调号正确处理、失败任务可诊断、旧报告兼容；手机视口 zh/en DOM 验证；root 与 /scorefollow 双构建验证。

## P0 第二批：可靠任务与真实样本门禁

1. 已实现任务持久化（分析及 OMR）：SQLite 元数据 + 仓库外私有输入/结果目录。提交输入与元数据后才入队，结果原子写入并记录校验摘要后才发布 completed；文件损坏或丢失不能复用为成功。
2. 已实现幂等提交：输入、规范化参数、种类及算法/质量版本共同确定缓存身份；处理中或已完成的相同请求返回同一任务 ID。失败后再次 POST 生成新 ID/attempt/retryOf，保留旧诊断；版本改变不复用缓存。
3. 已实现重启恢复：启动时独占数据目录，将未完成任务标为中断。兼容旧客户端，公开 status=failed、stage=interrupted、interrupted=true、errorClass=ServiceRestart；重新提交才重试，不自动续算之前的传感器阶段。
4. 取消：明确区分前端停止等待和服务端取消任务；队列取消立即生效，运行中取消在阶段边界生效。
5. 生命周期：TTL 只清理终态任务，有限队列、任务超时、原子结果落盘；确认权限与磁盘配额后删除过期输入。
6. 真实 Suzuki/Dotzauer 固定参数回放：需要人工核对首尾与小节边界，不能仅用高分证明对齐正确。用户确认 Suzuki PDF 不完整、小节未核验，音频完整；XML 是否完整尚不明确。旧 76 秒截取及 95/87 高分不是完整演奏真值。

存储配置：`ANALYSIS_DATA_DIR` 默认 `~/.local/share/scorefollow-analysis`，禁止指向仓库内部。目录 0700、输入/结果/SQLite 0600；模块导入不创建存储，服务 main 才初始化。TTL 只淘汰终态任务，以 finishedAt 计时，并清理对应输入/结果；活动任务不因 createdAt 超时被删除。队列上限仍为 4、工作线程仍为 2。取消、运行超时、孤儿文件清理及磁盘配额仍待后续实现。

## P1：算法适应能力

- 已实现：补救使用所选起始小节之后的完整 XML 候选，不受刚性 BPM 尾部裁切影响；只生成实际匹配范围内的完整小节边界，片段补救报告为 partial。
- 已实现：legacy 补救接受外部 pYIN 事件或内置事件，递归评分保留传感器输入；自动定位尚未获得可靠片段时间证据时也可进入补救。已可靠定位的裁切片段保留音符范围，不按面板 BPM 裁尾或强行改成整小节；QM 有效网格与用户显式同步仍保留各自语义。
- 已实现：局部锚点与首尾匹配事件冲突时禁止补救与可用走谱判定，提供检查谱面完整性/手动同步建议；支持的尾界取局部锚点而非全局速度外推。该门控不等于小节人工核验。
- 已实现：可靠自动定位片段在 QM 网格被拒绝、速度口径明显不符时，校准一次整体固定速度参考；不逐音重写期望时间，准点错音仍扣分。
- 自动补救候选须跨不同音高证据、起音、时间范围验证；保持准点错音扣分、停顿及错拍可见。
- 多片段录音拆分与用户选段；停顿与谱面休止区别处理。
- 局部速度曲线用于定位，保留独立节奏参考，避免逐音 warp 导致满分。
- 反复与跳房子先建演奏顺序模型，保留原 PDF 小节号，不直接改解析器后破坏走谱映射。
