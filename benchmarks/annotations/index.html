Barline Detection - Manual Annotation

Instructions

  1. Open annotation page: Click the link below to review a specific page.
  2. Review overlay:
    • Green lines = Our detections only (FP candidates)
    • Red lines = HOMR only (FN candidates)
    • Blue lines = Matched (within 4px tolerance)
  3. Toggle layers: Use checkboxes to show/hide overlays and adjust line width.
  4. Inspect systems: System breakdown shows TP/FP/FN counts and coordinates for each line.
  5. Annotate: In the text area, record:
    • Corrected system boundaries if needed: System 1: y=[165,193]
    • True bar positions: bars=[310, 558, 712, ...]
    • Notes on ambiguous cases: x=467 is valid barline touching beam
    • Clef changes, repeat signs, double bars, etc.
  6. Save: Click "Save Annotation" to download JSON. Place saved files in benchmarks/annotations/confirmed/.
